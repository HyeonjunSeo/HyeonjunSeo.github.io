Assignment 1 — Distance Minimization

This assignment investigates numerical methods for finding the shortest distance between a point and a nonlinear function. Two methods were implemented: Newton-Raphson and Golden-Section Search.

Problem Formulation

Given a point (x₀, y₀) and a function f(x), the squared distance between the point and a point on the function is

D²(x) = (x − x₀)² + (f(x) − y₀)²

The squared distance is minimized instead of the actual distance because taking the square root does not change the location of the minimum.

Newton-Raphson Method

Newton-Raphson uses the first and second derivatives of the squared-distance function to iteratively find a stationary point.

xn+1 = xn − D²′(xn) / D²″(xn)

Why does Newton-Raphson stop at a local maximum?

Newton-Raphson searches for a point where the derivative of the objective function is zero. However, a zero derivative only identifies a stationary point. It does not guarantee that the point is a minimum.

In this example, the iterations converge to a stationary point that corresponds to a local maximum of the squared-distance function. This occurs because Newton-Raphson is a local method, so its result depends on the initial guess and the local shape of the objective function.

The second derivative can be used to classify the stationary point:

D²″(x) > 0 → local minimum
D²″(x) < 0 → local maximum

To continue searching for the desired minimum, Newton-Raphson can be restarted with a different initial guess. Another option is to use Golden-Section Search over the specified interval. The resulting squared distances can then be compared to identify the minimum-distance solution.

Comparison of the Methods

Newton-Raphson uses derivative information and updates a single estimate of the solution. It can converge quickly, but its result depends on the initial guess and it can converge to an undesired stationary point.

Golden-Section Search does not require derivatives. Instead, it repeatedly reduces an interval containing the minimum. This makes it useful when derivatives are unavailable or when a bounded search interval is known.
